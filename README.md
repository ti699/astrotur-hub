# Astrotur Hub

Portal Corporativo — Astrotur Viagens e Turismo

Crie uma aplicação web chamada Portal Astrotur, destinada aos colaboradores da Astrotur Viagens e Turismo.

O objetivo principal do sistema é funcionar como um portal central de acesso aos sistemas internos da empresa, especialmente:

PatriGuard — sistema de Gestão de Patrimônio

HelpDesk — sistema de chamados e suporte de TI

Além disso, o portal deve apresentar informações resumidas sobre a frota da empresa, destacando visualmente um dos ônibus da Astrotur como elemento institucional.

Use como referência visual a imagem de dashboard fornecida, principalmente a organização em sidebar, cabeçalho, cards e dashboard corporativo. Porém, não copie o layout exatamente. Crie uma interface própria, moderna, elegante e profissional para a Astrotur.

      │

      │
      └── HelpDesk → https://astrotur-helpdesk.vercel.app/dashboard


Usar links externos normais e seguros.

Exemplo:

e

window.open(HELPDESK_URL, "_blank", "noopener,noreferrer");


5. CONFIGURAÇÃO DAS URLS

Mesmo que as URLs sejam conhecidas agora, não espalhar os endereços diretamente pelo código.

Centralizar em um arquivo de configuração.

Exemplo:

export const SYSTEMS = {
  patriguard: {
    name: "PatriGuard",
    description: "Gestão de Patrimônio",
    url: "https://patriguard.vercel.app/",
  },

  helpdesk: {
    name: "HelpDesk",
    description: "Suporte e Chamados de TI",
    url: "https://astrotur-helpdesk.vercel.app/dashboard",
  },
};


Dessa maneira, se futuramente o endereço de algum sistema mudar, basta alterar um único local.
